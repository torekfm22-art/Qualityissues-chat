# 텔레그램 연동 가이드

품질 부적합 톡을 텔레그램 그룹에서 자동 수집하고, 매일 엑셀로 정리합니다.

## 1. 봇 만들기

1. Telegram에서 `@BotFather` 열기
2. `/newbot` → 이름·username 설정
3. 발급된 토큰 복사 (`123456:AA...`)
4. `/setprivacy` → 봇 선택 → **Disable**  
   (끄지 않으면 그룹에서 `@봇` 멘션·명령만 보입니다)

## 2. 품질방에 초대

품질 부적합 공유 그룹에 봇을 추가합니다.

## 3. 앱에 토큰 등록

```bash
cp .env.example .env.local
# TELEGRAM_BOT_TOKEN=발급토큰
npm run dev
```

또는 UI **텔레그램 연동** 탭에 토큰을 붙여넣고 **설정 저장**.

## 4. 채팅방 ID 확인

1. 그룹에 아무 메시지(또는 샘플 부적합 톡)를 보냅니다.
2. UI에서 **채팅방 ID 검색** 클릭
3. 해당 방을 **허용에 추가** → **설정 저장**  
   (허용 목록을 비우면 봇이 들어 있는 모든 방에서 수집)

## 5. 상시 수집

**로컬 / 사내 PC (추천)**

```bash
TELEGRAM_BOT_TOKEN=... npm run collector
```

웹훅이 이미 걸려 있으면 폴링이 실패합니다. UI에서 **웹훅 해제** 후 실행하세요.

**공개 HTTPS 서버**

1. UI에 `https://your-domain/api/telegram/webhook` 입력
2. **웹훅 등록**
3. `npm run start` 로 웹 서버만 켜 두면 수신됩니다.

## 6. 일일 엑셀

- UI **오늘 수집** → **오늘 엑셀 다운로드**
- 또는 마감 시각(기본 23시 KST) 이후 `data/exports/품질부적합_YYYY-MM-DD.xlsx` 자동 생성

## 권장 톡 형식

```
품명: 프론트 브라켓
불량현상: 스크래치
공정번호: P-312
수량: 8 EA
로트: LOT-0328
```

또는:

```
품명 리어커버 / 치수과다 / P-108 / 3개
```

수집되면 봇이 ✅ 답장합니다 (설정에서 끌 수 있음).
