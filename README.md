# 품질톡 정리기

카카오톡·텔레그램 등 메신저 채팅방에 올린 **품질 부적합** 톡을 붙여넣으면, 품명·불량 현상·공정번호·수량 등을 표로 정리하고 엑셀(`.xlsx`)로 내려받는 현장용 웹 도구입니다.

## 기능

- 메신저 톡 붙여넣기 → 자동 파싱
- 인식 필드: 발생일시, 보고자, 품명, 품번, 불량 현상, 공정번호, 수량, 로트, 라인/설비, 조치내용, 비고
- 표에서 직접 수정·행 추가·삭제
- 엑셀 다운로드 (브라우저에서만 처리, 서버 전송 없음)
- 샘플 데이터로 바로 체험 가능

## 실행 방법

```bash
npm install
npm run dev -- -p 3847
```

브라우저에서 [http://localhost:3847](http://localhost:3847) 을 엽니다.

## 사용 예

라벨형:

```
품명: 프론트 브라켓 ASSY
불량현상: 도장 스크래치
공정번호: P-312
수량: 8 EA
```

슬래시 구분형:

```
품명 리어커버 / 치수과다 / 공정 P-108 / 3개
```

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- shadcn/ui
- ExcelJS (엑셀 생성)
